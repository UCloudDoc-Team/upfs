
# 创建文件系统

## 步骤一、进入文件存储 UPFS 产品

![](/images/upfs_guide/create1.png)

## 步骤二、在控制台页面选择创建文件存储的目标地域和项目组

目前文件存储在各地域的支持详情请参见[支持地域](/upfs/upfs_manual_instruction/region)章节或咨询技术支持。由于文件系统的访问是基于 VPC 的，并且目前在控制台上只允许选择和文件系统实例同一个项目组下的 VPC 进行访问，请您确定需要访问文件系统的主机所在项目组，并将文件系统实例创建在同项目中。

![](/images/upfs_guide/create2.png)


## 步骤三、创建文件系统

在创建页面，选择业务所需要容量的文件系统，并命名，确认无误后可点击「立即购买」完成创建。

![](/images/upfs_guide/create3.png)

### 创建参数说明

| 配置项 | 说明 | 备注 |
|--------|------|------|
| 地域 | 文件系统部署的地域 | 文件系统不支持跨地域访问，请选择与使用文件系统的云主机相同的地域 |
| 项目组 | 文件系统所属的项目组 | 目前仅支持同项目组内的VPC访问，请与使用主机保持在同一项目组 |
| 文件系统名称 | 自定义名称，用于标识文件系统 | 建议根据业务场景命名，便于识别 |
| 容量 | 文件系统的存储空间大小 | 起步为6000GiB，步长为1000GiB，容量上限可参考[产品限制](/upfs/upfs_manual_instruction/limit) |
| VPC网络 | 文件系统所在的VPC | 请选择与使用文件系统的云主机相同的VPC |
| 付费模式 | 文件系统的计费方式 | 目前支持按容量预付费，详见[产品价格](/upfs/price) |

### 注意事项

1. UPFS支持POSIX与NFS两种协议，请根据业务需求选择合适的协议类型。POSIX适用于高性能场景，NFS适用于标准文件访问场景。应用场景详情可参考[应用场景](/upfs/upfs_manual_instruction/application)章节。
2. 为保证 UPFS 达到最佳的性能体验，推荐UPFS和云主机UHost部署在同可用区。
3. 创建时的容量限制可参考[产品限制](/upfs/upfs_manual_instruction/limit)章节。
4. NFS协议需要在创建文件系统后单独创建NFS挂载点，详见[NFS挂载](/upfs/upfs_guide/nfs_mount.md)。

## 步骤四、创建完成后展示实例列表

![](/images/upfs_guide/create4.png)

创建成功后，可在文件系统列表页查看实例信息，包含：
- **资源ID**：文件系统的唯一标识
- **挂载地址**：POSIX协议挂载时使用的管理服务地址
- **容量/剩余容量**：文件系统的总容量和可用容量
- **付费信息**：计费模式和到期时间

**如果创建文件系统有问题，请及时联系UCloud技术支持。**
